# 🎮 Geometry Dash Style 2D Game

A 2D rhythm-based platformer game inspired by Geometry Dash, developed using Unity and C#. This project focuses on smooth gameplay mechanics, obstacle-based level design, and multiple player modes.

---

## 🚀 Features

* 🟦 Smooth player movement and controls
* 🔄 Multiple gameplay modes (Cube, Ball, Wave, etc.)
* ⚡ Physics-based mechanics using Unity Engine
* 🧱 Obstacle-based level design
* 💥 Collision detection and restart system
* 🎨 Clean 2D visuals and animations

---

## 🛠️ Tech Stack

* **Game Engine:** Unity
* **Language:** C#
* **Concepts Used:**

  * Physics Engine
  * Collision Detection
  * Game Loop
  * Script-based Player Control

---

## 📂 Project Structure

```
Assets/            # Game assets, scripts, scenes
Packages/          # Unity packages
ProjectSettings/   # Project configuration
```

---

## ▶️ How to Run

1. Open Unity Hub
2. Click **Open Project**
3. Select this project folder
4. Open the main scene
5. Click ▶️ Play

---

## 🎯 Objective

The goal of the game is to:

* Avoid obstacles
* Survive as long as possible
* Complete the level with precise timing
